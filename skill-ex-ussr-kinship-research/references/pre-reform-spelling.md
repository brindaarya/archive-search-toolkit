# Дореформенная орфография в запросах

Читайте этот файл перед поиском по текстам, напечатанным до 1918 года (газеты, адрес-календари, справочники, исповедные и метрические записи с распознанным текстом). Подробный разбор и таблицы — в `docs/02-дореволюционная-орфография.md` набора `archive-search-toolkit`.

## Правила

1. **Многие поисковики не приводят «ѣ», «і», «ѳ», «ъ» к современным буквам.** Запрос по-новому не находит текст по-старому, и пустая выдача здесь не означает отсутствия записи. Вносить в `search-log.csv` написание, в котором искали.
2. **Сначала зонд, потом пакет.** По каждому варианту сделать один запрос, сравнить число находок и дальше искать лучшей формой. Измеренный пример (Яндекс Архив, периодика 1860–1918): 21.08.2026 `іога` — 277, `йога` — 10; 05.11.2026 `іога` и `иога` — по 233, `йога` — 6, то есть поиск стал приводить «і» к «и», но «й» всё ещё отличает. Поведение поисковика меняется — замеряйте заново.
3. **Минимальный набор вариантов для имени:** современное, без «ё»; с «ъ» на конце (`Ильинъ`); с «і» перед гласной и «й» (`Дмитрій`, `Марія`); с «ѳ» в греческих именах (`Ѳедоръ`, `Аѳанасій`); для окончаний родительного падежа -аго/-яго (`Бронницкаго`); для предложного падежа «ѣ» (`въ Быковѣ`).
4. **Ять нельзя угадать по правилу** — только по словарю корней. Для нужных слов пробовать формы с «ѣ» и без.
5. **В заголовках дел ЦГА Москвы** искать ЗАГЛАВНЫМИ и по-современному: `БЫКОВО`, `БРОННИЦК`.
6. **После 1918 года** форма через «и» может быть частотнее, чем через «й» (`иога`), а старые написания встречаются до начала 1920-х.
7. **Распознанный текст — наводка.** Типичные замены OCR: ѣ → б, в; ъ → ь; і → i. Имена и даты проверять по образу страницы.

## Генератор вариантов

```bash
perl tools/perl/spelling-variants.pl --explain 'в Бронницком уезде'
perl tools/perl/ya-probe.pl --years 1860-1918 'хатха-йога'     # сравнивает варианты в Яндекс Архиве
```

Генератор — эвристика. Он не знает редких слов с ятем, падежных форм фамилий и топонимов; их формы задаёт исследователь.
