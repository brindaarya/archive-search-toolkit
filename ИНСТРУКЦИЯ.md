# Инструкция: что вам досталось и как этим пользоваться

Читайте эту страницу первой. Она написана для человека, который не обязан быть программистом.

## 1. Что это

Набор для поиска по онлайн-архивам: Яндекс Архив, ГПИБ, ЦГА Москвы, PastVu, Госкаталог. Он помогает:

* **находить старые документы** (метрические книги, газеты, справочники, фотографии),
* **искать правильно**: в дореволюционных текстах слова написаны по-другому, и обычный запрос ничего не находит,
* **не обмануться**: в наборе записаны ошибки, на которых мы уже обожглись.

Сами документы он не читает и выводов за вас не делает. Он приносит ссылки и фрагменты, а читаете и решаете вы.

## 2. Что нужно, чтобы начать

| Что | Для чего |
|---|---|
| Mac или Linux | скрипты в папке `tools/perl/` работают сразу, ничего ставить не нужно |
| Windows | скрипты в папке `tools/powershell/` (PowerShell 5.1 или 7) |
| Браузер Chrome | для Яндекс Архива |
| Аккаунт Яндекса (Яндекс ID) | Яндекс Архив с осени 2026 открывается только после входа |
| Claude Code или Claude (по желанию) | чтобы пользоваться навыком для родственных связей (раздел 7) |

## 3. Первый запуск за пять минут (Mac)

1. Откройте программу **«Терминал»** (Cmd+Пробел, наберите «Терминал»).
2. Наберите `cd ` (с пробелом после) и **перетащите в окно Терминала папку** `archive-search-toolkit`. Нажмите Enter.
3. Проверьте, что всё на месте:

   ```bash
   perl tests/run-tests.pl
   ```

   Внизу должно быть `12 ок, 0 ошибок`. Это проверка без интернета.
4. Посмотрите, как набор переписывает запрос в старую орфографию:

   ```bash
   perl tools/perl/spelling-variants.pl --explain 'в Бронницком уезде'
   ```

   Вы увидите варианты вроде `въ Бронницкомъ уѣздѣ`. Это то, что нужно вводить в поиск по старым текстам.

Если что-то из этого не сработало, смотрите раздел 9.

## 5. Яндекс Архив (через Chrome)

Яндекс Архив пускает только вошедших пользователей, поэтому он работает не из Терминала, а из вашего браузера.
Пароль вы вводите сами; скрипт его не видит.

1. Откройте в Chrome `https://yandex.ru/archive` и **войдите в Яндекс ID**.
2. Откройте консоль: **Cmd+Option+J** (Mac) или **Ctrl+Shift+J** (Windows).
   Если Chrome предупредит «не вставляйте код, которого не понимаете», вы можете сначала прочитать файл: он небольшой, комментарии
   на русском. Если Chrome не даст вставить текст, наберите в консоли `allow pasting`, нажмите Enter и вставьте ещё раз.
3. Откройте файл [tools/browser/ya-search.js](tools/browser/ya-search.js), **скопируйте всё** и вставьте в консоль. Нажмите Enter.
4. Теперь можно вводить команды (после каждой нажимайте Enter):

   ```js
   await yaProbe(['хатха-йога', 'хатха-иога'], { from: 1860, to: 1918 })
   ```
   Покажет, **сколько находок на каждое написание**. Берите то, где больше.

   ```js
   await yaSearch('в Бронницком уезде', { from: 1900, to: 1917 })
   ```
   Покажет первые 10 находок: дата, где лежит, фрагмент текста.

   ```js
   await yaPageText('<nodeId>', 4)
   ```
   Вернёт распознанный текст листа. `nodeId` и номер листа берутся из результата предыдущей команды (поля `node` и `page`).

5. **Ссылка на лист** собирается так: `https://yandex.ru/archive/catalog/<node>/<page>`. Откройте её в браузере и посмотрите скан.

Помните: если в консоль пришло «перенаправило на /archive», вы не вошли или сессия закончилась. Войдите заново.
Не запускайте больше нескольких десятков запросов подряд: условия сервиса запрещают массовое копирование.

## 6. Остальные источники (из Терминала)

Все примеры ниже запускайте из папки набора (раздел 3, шаг 2).

**ГПИБ** (дореволюционные справочники, адрес-календари, книги):

```bash
perl tools/perl/search-shpl.pl --max-pages 1 '+Бронницк* +земск*'
```

* `+слово` значит «обязательно», пробел значит «или», `слов*` значит «любое окончание».
* Чтобы искать сразу в нескольких написаниях:
  `perl tools/perl/search-shpl.pl "$(perl tools/perl/spelling-variants.pl --or 'исповедные ведомости')"`.
* В результате будет «скан N» и ссылка. **Это номер скана, а не печатной страницы**: проверяйте по колонтитулу.
* Текст страницы целиком: `perl tools/perl/search-shpl.pl --page-text <id>`.

**ЦГА Москвы** (метрические книги и др.). Запрос пишите ЗАГЛАВНЫМИ и по-современному:

```bash
perl tools/perl/search-cgamos.pl --years 1900-1917 БЫКОВО
perl tools/perl/search-cgamos.pl --section исповедные БРОННИЦК
```

* Результат: фонд, опись, дело, годы, ссылка на дело. Откройте ссылку: сканы там доступны без входа.
* Метрическое дело — **подшивка по всей губернии**, в заголовке десятки приходов. Нужный приход ищите по названию в описании.
* Ревизские сказки и исповедные ведомости названы **по уезду**, а не по селу: ищите по названию уезда.
* Разделы: `метрики` (по умолчанию), `ревизии`, `исповедные`, `обыски`, `личные`, `кладбища`, `иноверцы`.
* Чтобы сохранить таблицу для Excel: добавьте `--csv моя-таблица.csv`.

**PastVu** (фотографии и рисунки по месту):

```bash
perl tools/perl/Search-Pastvu.pl --place 'село Быково, Раменский район' --radius 800
```

Результат по радиусу — **выборка, а не полный список** (30 снимков из 202 в нашем опыте). Подробности — в [01-как-искать.md](docs/01-как-искать.md), п. 7.

**Windows.** Те же задачи решают исходные файлы из `tools/powershell/`, а Perl-версии работают, если у вас установлен Perl. Если PowerShell не запускает скрипт, откройте его в папке набора и выполните
`Set-ExecutionPolicy -Scope Process Bypass` (это действует только в этом окне), затем запускайте скрипт.
Примеры запуска — в начале каждого файла.

## 7. Навык для родственных связей

В папке `skill-ex-ussr-kinship-research/` лежит навык для **Claude Code** (автор — Denis Shiryaev, лицензия MIT; оригинал: github.com/DenisSergeevitch/ex-ussr-kinship-research, у нас копия с небольшими добавлениями): помощник, который ведёт генеалогическое дело по
метрическим книгам, военным и репрессионным базам и пишет итоговый отчёт. Он различает «найдено в документе» и «доказано»,
не склеивает однофамильцев и не считает копию одного источника двумя подтверждениями.

Установка: скопируйте папку в `~/.claude/skills/` и назовите её `ex-ussr-kinship-research`. Затем в Claude Code просто опишите
задачу: «Установи, был ли Иван Петров, 1890 г. р., из села Х, родственником Петра Иванова». Он сам задаст уточняющие вопросы.

Для живых людей навык минимизирует данные и не ищет их телефоны и адреса.

## 8. Как читать результаты, чтобы не ошибиться

1. **Ноль не значит «нет».** Это значит «не нашлось в этой орфографии, в этом источнике, сегодня». Пробуйте другие написания.
2. **Распознанный текст — подсказка.** Старую печать компьютер читает с ошибками (ѣ превращается в «б», ъ в «ь»). Открывайте скан и читайте глазами.
3. **Однофамильцы и омонимы.** «Быково» — десятки сёл в разных губерниях; «Быковский» — фамилия. Проверяйте уезд и соседние слова.
4. **Записывайте источник до листа:** фонд, опись, дело, лист, ссылка. Без этого находку не проверит ни другой человек, ни вы через год.
5. **Одна находка — это ещё не вывод.** Для родства нужны две независимые цепочки документов.
6. **Ведите журнал поиска**: что искали, где, когда, что нашлось. В том числе нули. Через неделю вы не вспомните, что уже пробовали.

## 9. Если что-то не работает

| Что видите | Что это значит | Что делать |
|---|---|---|
| `perl: command not found` | Perl не установлен (редко, на Windows) | Используйте `tools/powershell/` |
| `429` или «просит не торопиться» (ГПИБ) | вы слали запросы слишком часто | подождите 10–15 минут, увеличьте `--delay 3000` |
| Пусто в ЦГА Москвы, пауза, повтор | архив «придушивает» серии запросов | подождите; скрипт повторяет сам |
| Яндекс Архив: «перенаправило на /archive» | не вошли в Яндекс ID | войдите на `yandex.ru/archive` и повторите |
| Яндекс или любой сайт показывает проверку «я не робот» | сервис сомневается | **пройдите проверку сами в браузере**; не пытайтесь обойти скриптом |
| Кракозябры вместо русских букв (Windows) | файл сохранён без BOM | см. [docs/04-окружение.md](docs/04-окружение.md) |
| Нашлось много «мусора» | слово ловится внутри других слов или имён | добавьте уточняющее слово: уезд, волость, приход |
| Сайт изменился и скрипт перестал разбирать | такое бывает: разметка у сайтов меняется | сделайте один запрос вручную в браузере и сравните; сообщите тому, кто передал набор |

Подробнее по каждому сайту, с датами проверок: [docs/03-источники.md](docs/03-источники.md).

## 10. Что набор не делает и чего делать нельзя

* **Не обходит капчу, вход и ограничения сайтов.** И вы тоже не обходите.
* **Не заменяет архив.** Часть документов лежит только в читальных залах; например, в отделе рукописей РГБ нужен читательский билет и письмо-отношение организации, а самостоятельная фотосъёмка рукописей запрещена. Уточняйте правила перед визитом.
* **Не для слежки за живыми людьми.** Не ищите чужие телефоны, адреса, документы.
* **Не для массовой выгрузки.** Это инструмент для неторопливой личной работы: условия большинства сайтов запрещают копирование каталогов.
