# Яндекс Архив: работа через браузер со входом

## Что изменилось

Раньше (июль — сентябрь 2026) поиск и текст листа отдавались без входа, прямо в
`<script id="__NEXT_DATA__">`, и хватало `curl`. **С осени 2026 это не так.** Без входа в Яндекс ID
`/archive/search` и `/archive/catalog/<id>` отвечают HTTP 307 на `/archive`, на главной баннер
«просмотр доступен только авторизованным» (зафиксировано 22 октября и 1 ноября 2026; 5 ноября
повторилось при сборке этого набора).

Поэтому `ya-archive.pl`, `ya-probe.pl`, `ya-batch.pl` и `ya-archive.ps1` без входа получают пустоту.
Они оставлены как справочный код: разбор выдачи и параметры там верны, а транспорт устарел.

## Что делать

Вход выполняете **вы сами**, в своём браузере. Пароли, куки и токены скрипты не читают и не
передают. Затем запросы идут от вашей сессии, из страницы сайта.

1. Откройте `https://yandex.ru/archive` и войдите в Яндекс ID.
2. Откройте консоль (в Chrome — Cmd+Option+J), вставьте содержимое
   [tools/browser/ya-search.js](../tools/browser/ya-search.js), нажмите Enter.
3. Вызывайте:

   ```js
   await yaProbe(['йога', 'іога', 'иога'], { from: 1860, to: 1918 })   // сколько находок на вариант
   await yaSearch('в Бронницком уезде', { p: 1 })                      // выдача, 10 записей
   await yaPageText('<nodeId>', 4, /Быков/)                            // текст листа
   ```

Если вы не вошли или сессия закончилась, функции скажут об этом явно, а не вернут «0».

## Если работает Claude

Через Claude in Chrome: Claude открывает вкладку, где вы вошли, и выполняет тот же код там. Приёмы из
практики:

* вывод инструмента короткий (порядка 1500 знаков): результаты складывайте в `window.__x` и читайте
  порциями;
* результат блокируется, если в нём есть адрес со строкой запроса или куки: не возвращайте
  `location.href`;
* свою вкладку по окончании закрывать.

Встроенный браузер приложения без входа тоже не проходит.

## Что остаётся прежним

* Не указывайте `index`: пустой индекс = весь корпус (с `mass_media` пропадают сканы ЦГА Москвы).
* Пауза 2,5 с между запросами; серий больше нескольких десятков не гоняйте. Условия сервиса запрещают
  массовое копирование.
* Каталог: `/archive/catalog/<id>?text=…` фильтрует названия дочерних узлов; список узлов ЦГА Москвы —
  в [03-источники.md](03-источники.md).
* Орфография запроса — по [02](02-дореволюционная-орфография.md).
