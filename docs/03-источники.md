### Яндекс Архив: что ещё знать

* `?text=` **внутри каталога** (`/archive/catalog/<id>?text=…`) фильтрует **названия дочерних узлов**:
  так находят фонды и дела с точными годами. По номеру фонда или дела не ищет; внутри листа OCR
  не ищет, нужен прямой адрес листа.
* Узлы ЦГА Москвы, пригодные для обхода: корень `b3831e8d-dfcc-4221-9a3b-f4f526555411`,
  ф. 203 (Московская духовная консистория) `4d6e1847-9f6a-44de-b2ae-865339bfd4c9`, ф. 203 оп. 745
  (метрические книги) `a310a5c9-f982-4666-accb-91b9e64fbe54`, оп. 744 (ревизские сказки)
  `326c9b0b-c6a2-4c24-9561-c7c82bc30f6b`.
* Полноразмерный скан отдаётся по подписанной ссылке (живёт около суток) и качается в той же сессии
  с куками (`get_ya_image` в `ya-archive.pl`). Условия сервиса запрещают массовое копирование.

### ЦГА Москвы: коды разделов

| Раздел | Код `placeToSearch` |
|---|---|
| метрики | `73,60` |
| иноверцы | `67,68,69,70` |
| ревизии | `63` |
| исповедные | `65` |
| обыски (брачные) | `76` |
| личные дела | `77` |
| кладбищенские книги | `80` |

Заголовок дела — **подшивка по всей губернии**, приходы перечислены с номерами; искомый находят по
номеру позиции (колонка «Позиция» в выдаче). Сканы открыты без входа в полном разрешении
(`ajax/get_img.php?img_path=…`, ≈2350×3700), но запрос `curl` без сессионной куки Bitrix получает
0 байт: качать через браузер либо сначала взять `PHPSESSID`.
Фондовый каталог: `GET /fondi_i_opisi/?q=<одно слово>` — поиск **фразовый и строгий**, многословные
запросы дают ноль.
Неофициальный навигатор `epoisk.ru/?title=…&online=1` показывает, где лежат сканы и есть ли они
в Яндекс Архиве.

## РГБ (Российская государственная библиотека)

**Чтение** оцифрованных документов закрыто инструментом `rgb-viewer.pl` (проверен вживую 5 ноября 2026 на описи
ф. 814 «Ильины»: 760 страниц, доступ свободный, текстового слоя нет). **Поиска** по РГБ в наборе нет: `search.rsl.ru`
рисуется на клиенте, публичного API мы не знаем.

```bash
perl tools/perl/rgb-viewer.pl info 01004892721                      # что это, сколько страниц, можно ли читать
perl tools/perl/rgb-viewer.pl pages 01004892721 --page 7,9,15       # сохранить страницы как JPEG
perl tools/perl/rgb-viewer.pl text <ID> 12                          # текст страницы, если у документа есть текстовый слой
```

ID берётся из адреса просмотрщика: `viewer.rsl.ru/ru/rsl01004892721` → `01004892721`. Скрипт сначала спрашивает у API
сведения о документе и **отказывает**, если доступ не «free», нужна авторизация или документ читается только в
читальном зале. Чем он ограничен сознательно: правила РГБ запрещают скачивание документов целиком, поэтому за запуск
сохраняется не больше 40 страниц (`--limit`) с паузой между ними. Это инструмент чтения нужных листов, а не копирования фонда.

Как искать и читать вручную (проверено 9–11 октября 2026):

* **Поиск:** `search.rsl.ru/ru/search#q=<запрос>`; страницы выдачи — `#p=N&q=…`; сузить до авторефератов и
  диссертаций — `&col=autoref&col=disser`. Поиск полнотекстовый, но слова ищет врозь, кавычки почти не помогают
  («в Быкове» превращается в писателя Быкова). **Дореформенное написание работает именно без кавычек:**
  `Быково Бронницкаго уѣзда Воронцовъ-Дашковъ` дало 124 книги 1908–1915, а в кавычках с «ѣ» было 0. После смены
  запроса строка поиска иногда не перезапускает выдачу: надёжнее переходить по адресу с `#q=`.
* **Работа через Chrome со входом.** Вход в учётную запись РГБ выполняет пользователь сам. Выдачу читают текстом
  страницы; JavaScript на сайте блокируется, поэтому, в отличие от Яндекс Архива, скрипт для консоли не получится.
* **Доступ к тексту:** открытый замок и «Читать» — читается дома; закрытый замок или «Доступно только в РГБ» —
  только в читальном зале. «Читать» у диссертаций иногда открывает лишь оглавление, а автореферат при этом
  открыт целиком.
* **Просмотрщик:** `viewer.rsl.ru/ru/<ID>?page=N`. Лупа вверху справа ищет по тексту документа и показывает
  номера страниц. Страницы грузятся минуту и дольше: пустая заставка не означает отказ.
* **Оцифрованные описи** текстового слоя обычно не имеют (`/page/<N>/text` пуст): читать приходится глазами.
  Опись карточная: 6 карточек на скан.
* **Читальный зал отдела рукописей:** читательский билет **и** письмо-отношение организации (обновляется
  ежегодно); самостоятельная съёмка рукописей запрещена (по сайту на 22 августа 2026).

**Приёмы**

* **По указателю ищите каждого человека во всех формах:** «Фамилия» с каждой инициалой (А., А. О., А. Ф. и т. д.) по всем томам, и
  выписывайте все вхождения. Только так видно, что нужной формы нет совсем.
* **Ловушка созвучия.** В одном указателе могут стоять два человека с одинаковыми именем и фамилией, а то и псевдоним, ведущий на другого
  (запись «Ильин М. А. см. Осоргин М. А.» относится к писателю, а не к краеведу). Читайте отсылки «см.».
* **Пробелы в охвате.** Если страница в веб-архиве не сохранилась, это пробел, а не «нет»: записывайте его в журнал поиска (в нашем случае
  не сохранились отдельные страницы указателя).
* **Не склеивайте разные вещи.** Мемуары о соседней школе в селе не относятся к усадьбе в нём же; адресную привязку проверяйте по тексту.
* **Текстовый слой PDF.** Заранее оценить его нельзя по сырым байтам, если в файле есть `/ObjStm` (шрифты и карты ToUnicode спрятаны в
  сжатых потоках): сначала распаковать. Скрипт `get-pdf-text.pl --info` делает первую оценку, а полный разбор — без `--info`.
  **DjVu** ничем из набора не читается.
* **Объём.** Для большого корпуса (в нашем случае около 5,5 млн знаков мемуаров Серебряного века) работает поиск по именам через `grep` по скачанным
  текстам, а не по месту. Прогон показал, что ни Быкова, ни искомых лиц там нет: так «пусто» и записывалось, с перечнем просмотренного.
* **Сканы без текста** (например, тома «Литературного наследства») остаются на чтение глазами.

## Чтение сканов и письменные запросы

* Читальный зал отдела рукописей РГБ: читательский билет **и** письмо-отношение организации на имя
  заведующего (ежегодно обновлять). Самостоятельная съёмка рукописей запрещена. Сроки выдачи
  рукописей дольше, чем печатных книг (по информации сайта на 22 августа 2026).
* Когда онлайн-ресурсы исчерпаны, готовят письменные запросы в архивы по шифру (фонд / опись / дело)
  и вопросы родственникам; примеры — в навыке (`skill-ex-ussr-kinship-research`).
