# goskatalog — поиск по Госкаталогу Музейного фонда РФ

Доступ к [goskatalog.ru](https://goskatalog.ru) из PowerShell, без браузера и без авторизации.
Портал — это AngularJS-обёртка над открытым REST API; скрипт обращается к нему напрямую,
поэтому результаты приходят структурированными объектами, а не HTML.

Заточено под работу с изображениями: выгрузка контактных листов, пакетное скачивание
файлов в максимальном доступном качестве и поиск похожих предметов по своей картинке.

## Установка

```powershell
. .\goskatalog.ps1
```

При первом запуске скачиваются два справочника (музеи ~6 МБ и словари) в `cache\`.
Дальше они берутся с диска и обновляются раз в 30 дней.

## Быстрый старт

```powershell
. .\goskatalog.ps1

# найти и посмотреть всё разом
$r = Search-Gk -Query 'усадьба Быково' -WithImage -Max 300
$r | Export-GkGallery -Path .\results\bykovo.html -Open

# отобрать нужное глазами по галерее, потом скачать файлы
$r | Where-Object Typology -eq 'фотографии и негативы' | Save-GkImage -Path .\results\images

# и сохранить таблицу для дальнейшего разбора
$r | Select-Object Id,Name,Museum,GikNumber,Url | Export-Csv .\results\bykovo.csv -NoTypeInformation -Encoding UTF8
```

## Функции

### `Search-Gk` — поиск

| Параметр | Что делает |
|---|---|
| `-Query` | полнотекстовый поиск, то же поле, что на сайте. **Самый быстрый фильтр** |
| `-Name` | строгое вхождение в название предмета |
| `-Author` | вхождение в автора |
| `-Technology` | материал/техника: `фотобумага`, `холст`, `стекло` |
| `-Typology` | тип предмета: `фотографии`, `живопись`, `графика`, `документы`… (см. `Get-GkTypology`) |
| `-MuseumId` | один или несколько id музеев (см. `Find-GkMuseum`) |
| `-GikNumber` / `-InvNumber` / `-RegNumber` | точный номер |
| `-WithImage` / `-NoImage` | только с изображением / только без |
| `-Max` | сколько вернуть, страницами по 100 (по умолчанию 100) |
| `-Total` | дополнительно посчитать все совпадения — медленно, см. ниже |

```powershell
Search-Gk -Query 'усадьба Быково' -WithImage -Max 300
Search-Gk -Query 'Быково' -Typology 'фотографии' -WithImage
Search-Gk -Name 'Быково' -Technology 'стекло'          # негативы на стекле
Search-Gk -Author 'Шехтель' -WithImage -Max 100
Search-Gk -GikNumber 'ГНИМА НФ-ОФ-1348/254'
```

Возвращает `Id`, `Name`, `Museum`, `Typology`, `Authors`, `Technologies`, `GikNumber`,
`RegNumber`, `ImageCount`, `Thumb`, `Image`, `Url`.

### `Get-GkItem` — полная карточка

В выдаче поиска нет описания, датировки и размеров — их приходится добирать по одному предмету.

```powershell
Search-Gk -Query 'Быково' -WithImage -Max 30 | Get-GkItem |
    Select-Object Name,Period,Dimensions,Description,Museum
```

Добавляет `Description`, `Period` (как «29 января 1671 г.»), `StartDate`, `Dimensions`,
`ProductionPlace`, `FindPlace`.

### `Export-GkGallery` — контактный лист

Одна HTML-страница со всеми превью: заголовок ведёт на предмет в Госкаталоге,
сама картинка — на полное изображение. Быстрый способ просмотреть триста находок
за минуту вместо трёхсот кликов.

```powershell
$r | Export-GkGallery -Path .\results\bykovo.html -Title 'Усадьба Быково' -Open
```

Превью подтягиваются с сайта по ссылкам — файл весит десятки килобайт, но для
просмотра нужен интернет.

### `Save-GkImage` — скачивание

```powershell
$r | Save-GkImage -Path .\results\images            # главное изображение каждого предмета
$r | Save-GkImage -Path .\results\images -All       # все изображения (у предмета их бывает несколько)
$r | Save-GkImage -Path .\results\images -Size 350  # только превью
```

Имя файла — `<Id> <начало названия>.jpg`. Уже скачанное пропускается, так что
команду можно спокойно повторять; `-Force` перекачивает заново.

### `Search-GkByImage` — поиск по картинке

Тот же ИИ-поиск, что кнопкой на сайте. Ищет **визуально похожее**, а не тот же самый
предмет, но на практике хорошо находит другие съёмки того же объекта в других музеях.

```powershell
Search-GkByImage -Path .\my-photo.jpg | Select-Object Similarity,Name,Museum
Search-GkByImage -Path .\my-photo.jpg | Export-GkGallery -Path .\results\similar.html -Open
```

### `Find-GkMuseum`, `Get-GkTypology` — справочники

```powershell
Find-GkMuseum -Name 'Щусева'                       # -> Id 2732
Find-GkMuseum -Name 'краеведческий' -City 'Раменское'
Get-GkTypology
```

## Что важно знать про этот API

**Полнотекстовый `-Query` нечёткий.** Запрос `усадьба Быково` выдаёт заодно усадьбу
Марфино архитектора Быков**ского**. Плюс сёл Быково в России много: по `-Name 'Быково'`
первыми идут отписи XVII века про село Быково Кашинского уезда. Для подмосковного
Быкова надёжнее сужать: `-Query 'усадьба Быково Владимирская церковь'`, `-Query 'Быково
Раменский'` или искать в фондах конкретного музея через `-MuseumId`.

**Подсчёт совпадений медленный.** `-Total` иногда уходит в таймаут — счёт по всей базе
не оптимизирован. Поэтому он выключен по умолчанию; выдача при этом работает нормально.

**Фильтры без текста почти не работают.** `-MuseumId` или `-Typology` сами по себе
заставляют сервер перебирать миллионы записей и обычно не дожидаются ответа. Вместе с
`-Query` — отвечают за секунды. Всегда задавайте текст запроса.

**Разрешение изображений ограничено.** Публичные копии — примерно до 1024 px по длинной
стороне, оригиналы наружу не отдаются. `-Size 2000` просто берёт максимум, что есть.
За полным разрешением надо обращаться в музей-хранитель (`Museum` в выдаче).

**Ищутся только опубликованные предметы** (`statusId = 6`) — то же, что видно на сайте.

## Структура

```
goskatalog.ps1   библиотека функций
cache\           справочники музеев и словарей (создаётся сам)
results\         выгрузки: галереи, csv, images\
```
