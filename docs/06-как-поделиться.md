# Как поделиться набором (для того, кто его передаёт)

## Что готово

Папка набора самодостаточна: скрипты, документация, офлайн-тесты и копия навыка. Контрольный список перед
передачей (все пункты выполнены 7 ноября 2026):

- [x] `perl tests/run-tests.pl` — 25 проверок без интернета проходят;
- [x] все `.pl` компилируются, `ya-search.js` проходит проверку синтаксиса;
- [x] в `.md` нет битых относительных ссылок;
- [x] нет личных данных и секретов (имена, почта, токены, абсолютные пути): проверено поиском по папке;
- [x] нет кэшей и временных файлов (`cache/`, `_scans/`, `.DS_Store`);
- [x] чужой код (навык) подписан: автор, лицензия, перечень наших изменений.

## Что решить самому

1. **Лицензия.** Выбрана MIT, © 2026 Brinda Arya (файл `LICENSE` в корне). У навыка своя лицензия (MIT, Denis Shiryaev),
   она сохранена внутри его папки, и в корневом `LICENSE` это оговорено. Имя автора попадает в публичный файл:
   если когда-нибудь понадобится другое, меняйте его до публикации.
2. **Как передавать** (по возрастанию усилий):
   * **Архив.** Отправить `archive-search-toolkit-v1.0.0.zip`: получатель распаковывает и читает `ИНСТРУКЦИЯ.md`.
     Подходит для нескольких знакомых.
   * **Репозиторий на GitHub.** Лучше для широкой аудитории и для обновлений: `git init`, залить на GitHub
     (`LICENSE` уже есть). Публикация общедоступна и необратима де-факто (копии и кэши остаются), поэтому делайте её
     сознательно.
   * **Плагин** для Claude Code с `plugin.json` — позже, если понадобится установка одной командой.
3. **Навык.** Он чужой. Лучше ссылаться на оригинал и передавать получателям ссылку, а наши добавления
   (`references/pre-reform-spelling.md`, записи в `seed-sources.md`) предложить автору. Копия в наборе оставлена
   для удобства и работы офлайн.

## Что не входит в набор и почему

- **Дела конкретных людей** («Поиск людей по архивам» и подобные папки): это ваши семейные данные.
- **Результаты поисков** (CSV, отчёты, сканы по вашему проекту) и прочие материалы по теме «Быково».
- **Памятка к стороннему сервису с личным токеном** (`searcher-памятка-…`): токен в открытом виде. Если такой файл
  когда-либо показывали в переписке или выкладывали, токен лучше заменить.
- Скрипты, привязанные к одному проекту, и сборщики документов через Word (COM).

## Что получатель должен знать сразу

- Яндекс Архив требует вход в Яндекс ID: скрипты из терминала к нему не подходят, нужен `tools/browser/ya-search.js`.
- `guides.rusarchives.ru` не отвечает без осознанного ключа `--insecure` (у сайта неполная цепочка сертификатов).
- Сайты меняются: перед большим прогоном — один пробный запрос. Даты проверок — в `docs/03-источники.md`.
- Набор рассчитан на неторопливое личное использование, а не на выгрузку каталогов.

## Как обновлять

Меняйте скрипты и документы, добавляйте строку в `CHANGELOG.md`, поднимайте `VERSION`, прогоняйте
`perl tests/run-tests.pl`, пересобирайте архив. Даты проверок в `docs/03-источники.md` обновляйте только после реального запроса.
