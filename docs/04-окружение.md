# Окружение: что нужно и какие бывают ловушки

## Какую версию скриптов брать

| У вас | Берите | Что нужно поставить |
|---|---|---|
| **macOS / Linux** | `tools/perl/` | ничего: Perl и `curl` уже есть (модуль `JSON::PP` входит в состав Perl) |
| **Windows** | `tools/powershell/` | Windows PowerShell 5.1 или PowerShell 7; `curl.exe` из Windows 10+ |
| **macOS / Linux с PowerShell 7 (`pwsh`)** | `tools/powershell/` | установщик PowerShell 7 |

Perl-версии покрывают **все** инструменты набора: Госкаталог, ГПИБ и ИнфоРост (поиск и выгрузка сканов),
ЦГА Москвы, PastVu, rusarchives и istmat, текст из PDF, генератор написаний. PowerShell-версии оставлены как
исходные; на Windows можно пользоваться любой из двух.

Проверка, что всё на месте:

```bash
perl -v | head -2
curl --version | head -1
perl tests/run-tests.pl            # офлайн-тесты: разбор страниц и орфография
```

## macOS: ловушки

* **PowerShell нет**, `python3` — заглушка, просящая поставить Xcode CLT. Работают `perl`, `ruby`,
  `curl`, `jq`, `sips`.
* **`LANG` пуст**, поэтому `ARGV` в Ruby приходит как ASCII-8BIT и кириллица в имени файла ломает
  интерполяцию строк. Лечится: `ARGV.map! { |a| a.dup.force_encoding('UTF-8') }`. В Perl-скриптах
  набора аргументы декодируются сами.
* **zsh: переменная `path` связана с `PATH`.** Строка `read -r id path title` в цикле стирает `PATH`,
  и дальше всё падает с «command not found». Называйте переменную иначе (`ipath`).
* **Файловая система нечувствительна к регистру**: маска `*.{jpg,JPG}` находит один файл дважды.

## Windows (PowerShell): ловушки

* **Файлы с кириллицей сохраняйте в UTF-8 с BOM.** Без BOM Windows PowerShell 5.1 читает файл как ANSI
  и падает на разборе строк. Починка:

  ```powershell
  $f = '.\script.ps1'
  $t = [System.IO.File]::ReadAllText($f, [System.Text.UTF8Encoding]::new($false))
  [System.IO.File]::WriteAllText($f, $t, (New-Object System.Text.UTF8Encoding($true)))
  ```
* В PowerShell 5.1 ответы без `charset` нужно декодировать из `RawContentStream` как UTF-8 вручную,
  иначе кириллица «ломается».
* **`$pid` — константа**, переменную так называть нельзя.
* Из `curl.exe` вызывайте `-s`, не `-sS`: вывод в stderr становится терминирующей ошибкой при
  `$ErrorActionPreference = 'Stop'`.
* Серия частых запросов: ЦГА Москвы отдаёт 200 с нулём байт — в скриптах предусмотрены пауза и
  повтор.
* **Не вошли в набор**, потому что завязаны на Word через COM: `md-to-doc.ps1`, `md-to-pdf.ps1`,
  `build-a5.ps1`. На macOS это заменили `build_docx.rb` и печать через headless Chrome.

## Куда складывать результаты

Скрипты пакетного прогона пишут в `results/` рядом с собой: сырой CSV (`*-raw.csv`) и отчёт
Markdown (`*-report.md`). Параметры `--csv`, `--md`, `--suffix` позволяют прогнать заново и
сравнить с прежним результатом, а не затереть его.
